Le positionnement en CSS

Chaque type de positionnement est expliqué avec un exemple réel : un cube dans une pièce, pour une visualisation claire et logique.

Position : static (cube normal)

Le cube est posé naturellement dans la pièce et suit le flux normal.

Cube
position: static;

Position : relative (cube déplacé légèrement)

Le cube reste dans le flux mais est décalé par rapport à sa position initiale.

Cube
position: relative; top: 20px; left: 20px;

Position : absolute (cube collé au mur)

Le cube est retiré du flux et positionné par rapport à la pièce.

Cube
position: absolute; top: 20px; right: 20px;

Position : fixed (cube du gardien – zone précise)

Le cube reste visible dans une zone précise seulement. Il ne flotte pas sur toute la page.

Cube
Simulation pédagogique du fixed (zone limitée)

Position : sticky (cube qui suit puis se bloque)

Le cube défile normalement puis se bloque à une position donnée.

Cube
position: sticky; top: 10px;
