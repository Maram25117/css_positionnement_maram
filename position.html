Maîtriser le Positionnement CSS

Guide interactif étape par étape

1. Position: Static

C'est l'état par défaut. L'élément suit le flux normal. Les propriétés top, left, right, bottom et z-index n'ont aucun effet.

Cube 1
Static (top/left ignorés)
.cube-static {
  position: static;
  top: 20px; /* Aucun effet */
}

2. Position: Relative

L'élément est décalé par rapport à sa position d'origine. L'espace initial qu'il occupait est conservé (réservé), il ne pousse donc pas ses voisins.

Voisin
Relative
Voisin
.cube-relative {
  position: relative;
  top: 25px;  /* Se décale vers le bas */
  left: 45px; /* Se décale vers la droite */
}

3. Position: Absolute

L'élément est retiré du flux normal. Important : pour que l'enfant se place correctement, son parent doit être positionné (hors de static, ex: relative ou absolute).

Parent Relatif
Absolute
.parent {
  position: relative; /* Référentiel (Non-static) */
}
.enfant-absolute {
  position: absolute;
  top: 15px;   /* 15px depuis le haut du parent */
  right: 15px; /* 15px depuis la droite du parent */
}

4. Position: Fixed

L'élément est retiré du flux et reste totalement immobile par rapport au viewport (fenêtre du navigateur), peu importe le défilement.

FIXED

SCROLLEZ CE CADRE :

Le cube violet reste fixé au coin du cadre noir.

Il ne bouge jamais, même si ce texte défile.

.cube-fixed {
  position: fixed;
  bottom: 15px;
  right: 15px;
}

5. Position: Sticky

L'élément se comporte comme un "Relative" puis se bloque comme un "Fixed" lorsqu'il atteint un seuil défini lors du scroll (ex: top: 0).

Défilez vers le bas...
STICKY
Le cube jaune reste collé en haut pendant le défilement.
.cube-sticky {
  position: sticky;
  top: 0; /* Se bloque au sommet du parent */
}
